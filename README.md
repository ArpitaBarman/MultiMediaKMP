# Barman Multimedia

Android app with a Navigation Drawer containing four features: Broadcast Receiver, Image Scale, Video, and Audio. The app uses a gray, classic Android interface and a Kotlin Multiplatform module for shared models.

The Android application ID and namespace are `com.barman.multimedia`. Shared Kotlin models also use `com.barman.multimedia`; the shared Android library uses `com.barman.multimedia.shared` for its generated resources.
